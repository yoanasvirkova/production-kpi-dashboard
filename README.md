# Production KPI Dashboard

This is a beginner-friendly manufacturing dashboard built with Python and Streamlit.

The goal of the project is to monitor production KPIs such as output, defect rate, machine downtime, and efficiency.

## Features

- Loads production data from CSV
- Calculates manufacturing KPIs
- Filters data by machine and shift
- Visualizes production trends
- Shows defect rate and downtime charts
- Generates simple process improvement insights

## Technologies Used

- Python
- pandas
- matplotlib
- Streamlit

## KPIs Calculated

- Total units produced
- Defective units
- Defect rate
- Production efficiency
- Machine downtime

## Why I Built This

I built this project to practice data analysis, dashboard creation, and KPI monitoring in a manufacturing context.

This project is related to my interest in AI, automation, and process improvement.
